# PPSSPP WEB

Interface web inspirada no PPSSPP, feita em HTML/CSS/JavaScript e pronta para GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. Abra **Settings → Pages**.
4. Em Source, escolha **Deploy from a branch**.
5. Selecione `main` e `/root`.
6. Salve e abra o endereço do GitHub Pages.

## Importante

Esta versão é a interface/protótipo. Um navegador não executa `.exe` ou `.apk` diretamente.

Para executar jogos PSP de verdade no navegador, é necessário integrar um emulador PSP compatível com WebAssembly/WebGL/WebGPU. A interface já está separada para essa integração.

Use somente jogos, BIOS/firmware e arquivos que você tenha direito de utilizar.
